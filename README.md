# GestureFlow

GestureFlow is a computer vision-based application designed to control presentations and documents using hand gestures. 

## Features
* **Hand Tracking**: Uses MediaPipe for robust hand tracking.
* **Presentation Control**: Control PowerPoint presentations seamlessly using intuitive gestures.
* **Document Navigation**: Manage documents and presentations directly from the application.

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Anushka-Bharadwaj/GestureFlow.git
   cd GestureFlow
   ```

2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage
Run the main application:
```bash
python main.py
```

> **Note:** This application uses `comtypes` for interacting with Microsoft Office applications and is currently only supported on **Windows**.
